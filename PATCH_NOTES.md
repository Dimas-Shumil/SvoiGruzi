# СВОИ ГРУЗЫ — контрольная точка 2026-10-11

В этой версии исправлены замечания по CRM без перепридумывания существующей логики «Эвакуатор19».

## Что изменено

- статусы заявок: только `Новая`, `Запланированная`, `Выполнена`, `Отменена`;
- удалён сценарий «Взять в работу»;
- новая/ручная форма заказа возвращена к структуре «Эвакуатор19», добавлены только поля грузоперевозок;
- исправлено редактирование клиента: клики по полям больше не переоткрывают карточку;
- унифицированы стрелки всех выпадающих списков;
- раздел «Активность» удалён из интерфейса;
- раздел «Партнёры» удалён из интерфейса;
- смена пароля удалена, в настройках показано «Уведомления скоро появятся»;
- автопарк оставлен как основной новый модуль CRM;
- `car.html` полностью получает данные автомобиля из БД;
- в форме автомобиля добавлены зона работы, текст характеристик, текст блока перевозок и список грузов;
- сохранена безопасная загрузка JPG/PNG/WebP до 5 МБ;
- public-заявка всегда создаётся со статусом `Новая`;
- development Origin разрешает и `localhost`, и `127.0.0.1`, production остаётся строгим.

## Важно после замены файлов

В этой версии есть новая Prisma-миграция. Выполнить:

```cmd
npm install
npx prisma generate
npx prisma migrate deploy
npm run vehicles:seed
npm run dev
```

Не удалять `.env` и `prisma/dev.db`.
