Распакуйте содержимое архива в корень проекта с заменой файлов.
Перезапустите приложение: pm2 restart svoi-gruzi
Новые зависимости и миграции не нужны. Работает через HTTPS или localhost.
Плашка появляется при загрузке публичных страниц. Позже и отказ в системном диалоге откладывают её на 48 часов.
На iPhone установка выполняется через Поделиться → На экран Домой.
В установленном приложении и после зарегистрированной установки предложение скрывается. Браузеры не предоставляют универсальный способ определить установку из другого браузера/профиля; на iOS установка вручную может быть распознана только после первого запуска приложения.
Service worker публичной части не хранит страницы, API и персональные данные в кеше. Без сети показывает сообщение; оформление заявки требует интернета. Push админ-панели остаётся отдельным.
