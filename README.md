# СВОИ ГРУЗЫ

Публичный сайт грузоперевозок и закрытая CRM для заявок, клиентов, автопарка, задач и финансов.

## Стек

HTML5 / SCSS / Vanilla JS, Node.js 22+, Express 5, Prisma 6 + SQLite, Argon2id, Nodemailer, PM2, Nginx.

## Обновление существующей локальной версии

Сохраните свой `.env` и `prisma/dev.db`, затем замените файлы проекта содержимым архива.

```cmd
npm install
npx prisma generate
npx prisma migrate deploy
npm run vehicles:seed
npm run dev
```

Сайт: `http://localhost:3000`  
CRM: `http://localhost:3000/control`

## CRM

- Обзор;
- Заявки — заявки с сайта + ручное создание, статусы Новая / Запланированная / Выполнена / Отменена;
- Клиенты — существующая логика добавления, редактирования, истории и удаления сохранена;
- Автопарк — добавление/редактирование/удаление автомобилей, характеристики, публикация, галерея и безопасная загрузка фото;
- Задачи — существующая логика сохранена;
- Финансы и CSV — существующая логика сохранена;
- Настройки — заглушка «Уведомления скоро появятся».

`car.html` получает данные конкретной машины из БД. Название, тексты, характеристики, зона работы, список грузов и фотографии редактируются через раздел «Автопарк».

## Безопасность

Node слушает только loopback (`127.0.0.1`). В production наружу выставляется только Nginx 80/443. CRM использует серверные сессии, Argon2id, HttpOnly/Secure cookies, CSRF, Origin validation, CSP и rate limits. В development разрешены `localhost` и `127.0.0.1`, а production принимает только `APP_ORIGIN`.

Перед production:

```cmd
npm test
npm audit --omit=dev
```

См. `SECURITY_AUDIT.md` и `deploy/SECURITY.md`.
